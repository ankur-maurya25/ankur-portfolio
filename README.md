# Ankur Maurya - Portfolio Website

![Portfolio Screenshot](assests/images/ankurm.png)

A professional, responsive portfolio website showcasing my skills, projects, and services as a PHP Full Stack Developer. Designed with modern UI principles, clean code, and optimized for speed and accessibility.

## 🔗 Live Demo
[View Live Portfolio](https://ankur-maurya25.github.io/ankur-portfolio/)

## 🛠️ Tech Stack
This project is built strictly without heavy frameworks to ensure maximum performance and maintainability:
- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom animations, responsive layouts, and modern UI variables.
- **JavaScript (Vanilla)**: Smooth scrolling, interactive side menus, intersection observers, and typing animations.

## ✨ Features
- **Responsive Design**: Flawless experience across Desktop, Tablet, and Mobile devices.
- **Dynamic Animations**: Smooth scroll reveals, hover effects, and a custom typing animation.
- **Interactive Navigation**: Sticky header with active section highlighting and a mobile side menu.
- **Project Showcase**: Detailed cards with tech stacks, factual features, and links to live demos/code.
- **Skill Progress Bars**: Animated skill representations triggering on scroll.
- **Accessible & SEO Optimized**: Fully equipped with meta tags, Open Graph data, and ARIA labels.

## 🚀 Installation & Usage
To run this project locally, follow these simple steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/ankur-maurya25/ankur-portfolio.git
   ```
2. **Navigate to the directory**
   ```bash
   cd ankur-portfolio
   ```
3. **Open the project**
   Simply open `index.html` in your favorite web browser or use a tool like VS Code Live Server for hot-reloading.
